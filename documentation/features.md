# Fonctionnalités

## Périodes

L’utilisateur peut consulter un semestre, une année universitaire ou tous les semestres disponibles. Une période sans note reste identifiable mais n’entre pas dans les moyennes et graphiques.

## Synthèse

La synthèse met en avant :

- la moyenne de la période ;
- la position par rapport à la promotion ;
- les résultats modifiés, nouveaux puis récents ;
- les moyennes par UE sur une toile d’araignée.

Un clic sur une note ouvre la vue Notes, place la ligne concernée à l’écran et la rend visible.

## Notes

Deux présentations sont disponibles :

- **Par module**, sélectionnée par défaut ;
- **Liste**, adaptée à la recherche et aux filtres.

Les statistiques de promotion sont chargées à la demande. La ligne affiche la note, le coefficient utile, la moyenne, le rang et une distribution compacte selon la largeur disponible.

Une note ouverte ou visible pendant environ 30 secondes est marquée comme vue. L’ordre reste stable pendant la consultation.

## Analyses

Les graphiques répondent à des questions précises :

- dynamique des résultats ;
- écart par module ;
- répartition des notes ;
- moyenne par UE comparée à la promotion.

Les périodes et valeurs insuffisantes sont ignorées plutôt que remplacées artificiellement.

## Semestres et documents

La page Semestres regroupe les périodes par année et donne accès aux téléchargements. Une seule fenêtre propose ensuite :

- un semestre, une année ou tout le parcours ;
- les bulletins officiels disponibles ;
- le relevé officiel ;
- un bulletin PulseNotes configurable.

Le PDF PulseNotes est un export personnalisé non officiel. Il peut inclure synthèse, UE, modules, évaluations, rangs et graphiques selon le profil choisi.

## Partage d’une note (installation personnelle)

Depuis le détail d’une note, un utilisateur peut créer une URL publique aléatoire. Cette page expose uniquement la note sélectionnée, le profil affiché et ses statistiques.

Un lien peut être copié, remplacé ou révoqué depuis les paramètres. Si l’évaluation disparaît du relevé, la page publique affiche que la note a été supprimée.

## Navigation clavier

| Raccourci | Action |
| --- | --- |
| `Alt+1` à `Alt+4` | Ouvrir les quatre vues principales |
| `Alt+←` / `Alt+→` | Vue précédente ou suivante |
| `/` | Rechercher une note |
| `Alt+S` | Ouvrir le sélecteur de période |
| `Alt+L` / `Alt+G` | Liste / regroupement par module |
| `Alt+D` | Ouvrir la déconnexion disponible |
| `?` | Afficher l’aide clavier |

Les équivalents des touches AZERTY sont acceptés et les raccourcis sont neutralisés pendant la saisie.
